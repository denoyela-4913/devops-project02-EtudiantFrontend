src/app/app.config.ts

appConfig
Type : ApplicationConfig
Default value : { providers: [ provideHttpClient(withInterceptors([authInterceptor])), provideZoneChangeDetection({ eventCoalescing: true }), provideRouter(routes)] }

Configuration racine de l'application : routage, détection de changements et client HTTP (avec injection du JWT via authInterceptor).

src/app/core/guards/auth.guard.ts

authGuard
Type : CanActivateFn
Default value : () => { const authService = inject(AuthService); const router = inject(Router); return authService.isLoggedIn() ? true : router.parseUrl('/login'); }

Autorise l'accès si un JWT est présent ; sinon redirige vers /login.

src/app/core/interceptors/auth.interceptor.ts

authInterceptor
Type : HttpInterceptorFn
Default value : (req, next) => { const authService = inject(AuthService); const router = inject(Router); const token = authService.getToken(); const authReq = token ? req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }) : req; return next(authReq).pipe( catchError((error: unknown) => { if (error instanceof HttpErrorResponse && error.status === 401 && !req.url.includes(LOGIN_URL)) { authService.logout(); router.navigate(['/login']); } return throwError(() => error); }) ); }

Ajoute Authorization: Bearer <token> à chaque requête sortante si l'utilisateur est connecté. Sur une réponse 401 (hors /api/login, où 401 signifie juste "identifiants invalides"), déconnecte l'utilisateur et le redirige vers /login : le JWT est expiré ou invalide.
LOGIN_URL
Type : string
Default value : '/api/login'
